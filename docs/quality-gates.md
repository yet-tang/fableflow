# 质量门禁

## G1：选题

通过条件：

- 概念包含可讲述的因果机制，而不只是一个定义。
- 普通观众能在现实中找到对应体验。
- 可构造不依赖公式的寓言。
- 不涉及无法在短视频中妥善表达的高风险专业建议。

## G2：故事方向

每项 1–5 分，总分低于 22 不进入脚本阶段。

| 维度 | 问题 |
|---|---|
| 机制准确 | 关键事件是否由概念机制驱动？ |
| 故事独立 | 不知道概念时，故事是否仍成立？ |
| 钩子强度 | 前 3 秒是否出现异常或风险？ |
| 延迟揭晓 | 前 70% 是否没有直接泄题？ |
| 可视化 | 是否能用 10–15 个清晰镜头表现？ |
| 现实迁移 | 结尾是否容易映射到真实生活？ |

## G3：视觉资产

逐张检查：

- 角色脸型、发型、服装、年龄感一致。
- 画面符合 `style-bible.md`。
- 主体在手机屏幕上足够清晰。
- 画面没有生成文字、水印或多余肢体。
- 字幕安全区可用。
- 镜头之间时间、天气和空间连续。

标记状态：`approved`、`regenerate` 或 `reuse_alternative`。

## G4：成片

### 内容

- 概念定义准确，未夸大适用范围。
- 隐喻映射有解释，简化项有必要时说明。
- 现实案例不构成医疗、法律或投资建议。

### 叙事

- 3 秒内形成问题。
- 中段每 10–15 秒至少一次新信息或局势变化。
- 猜测节点有真实停顿。
- 结尾不是重复定义，而是提供迁移判断句。

### 视听

- 人声清晰，音乐不盖过旁白。
- 字幕无错别字和术语错误。
- 关键画面不被平台 UI 遮挡。
- 已加入必要的 AI 生成内容标识。

## 数据复盘阈值

首批 10 期只做相对比较，不预设绝对爆款阈值。优先比较：

1. 同类选题中的 3 秒留存。
2. 不同时长的完播率。
3. 故事型结尾与解释型结尾的转发率。
4. 评论区猜中率与评论率的关系。
5. 角色复用是否提升回访和关注。
