# 质量门禁

## G1：选题

- 概念包含可讲述的因果机制。
- 普通观众能找到现实体验。
- 可构造不依赖公式的寓言。
- 不属于无法在短视频中妥善表达的高风险专业建议。

## G2：故事方向

每项 1–5 分，总分低于 22 不进入脚本阶段：机制准确、故事独立、钩子强度、延迟揭晓、可视化、现实迁移。

## G3：视觉锚点

逐张检查：

- 角色脸型、发型、服装、年龄感一致。
- 场景地理、井台、道路和光源方向稳定。
- 构图适合 9:16 与字幕安全区。
- 图片没有文字、水印、多余肢体和重复人物。
- 参考帧明确表现镜头初始状态。

标记：`approved`、`regenerate` 或 `reuse_alternative`。

## G4：Seedance 视频片段

每条片段至少检查：

| 维度 | 通过标准 |
|---|---|
| identity_consistency | 角色仍能被识别，脸、服装和年龄感没有重设计 |
| motion_quality | 主要动作自然、完整，没有肢体或物体突变 |
| camera_adherence | 只执行约定的主要运镜，没有失控旋转或突然变焦 |
| scene_continuity | 时间、天气、光线、水位和物体数量与前后镜头一致 |
| artifact_free | 手、桶、井壁、群像和背景没有明显畸变 |
| audio_usability | 原生声音可独立使用或可安全静音 |
| editability | 有清晰入点、出点，能放进时间线 |

处理规则：

- 关键身份、动作或连续性失败：`regenerate`。
- 原生音频失败但画面可用：静音，不重生成。
- 连续失败两次：降低动作复杂度。
- 仍失败：`fallback_still`，执行静帧微动方案。

## G5：最终成片

### 内容

- 概念定义准确，未夸大适用范围。
- 隐喻映射明确，必要简化得到说明。
- 揭晓前没有术语泄露。

### 叙事

- 3 秒内形成问题。
- 中段每 10–15 秒有新信息或局势变化。
- 猜测节点有真实停顿。
- 结尾提供迁移判断，而不是重复定义。

### 视听

- 独立旁白清晰且逐字准确。
- Seedance 原生声音没有盖住旁白。
- 相邻片段角色和场景没有明显跳变。
- 字幕无错别字，不挡关键主体。
- 概念揭晓字卡由剪映生成，不来自 AI 图片或视频文字。
- 已加入必要的 AI 生成内容标识。

## 数据复盘

首批 10 期以相对比较为主：

1. 不同钩子的 3 秒留存。
2. 不同时长的完播率。
3. 视频运动镜头与静帧镜头对完播和成本的影响。
4. Seedance 首次通过率和重生成成本。
5. 角色一致性是否提升关注和回访。
