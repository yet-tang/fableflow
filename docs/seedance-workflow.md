# Seedance 镜头生产规范

## 1. 定位

Seedance 位于 gpt-image-2 和剪映之间：

- gpt-image-2 负责角色身份、服装、场景空间和构图锚点。
- Seedance 负责角色动作、物体运动、运镜、光影变化和可选环境声。
- 剪映负责精确旁白、字幕、节奏、概念揭晓、BGM 和最终混音。

不要让 Seedance 同时承担角色设计、复杂剧情、准确知识口播和最终剪辑。

## 2. 默认生成模式

### image_to_video

默认首选。使用已经通过 G3 的 gpt-image-2 参考帧，生成一个清晰动作。

适合：

- 固定角色出场。
- 井水下降、桶落下、人物回头等单动作。
- 需要服装和场景稳定的镜头。

### multimodal_reference

当镜头需要同时参考角色图、场景图、动作视频或声音氛围时使用。

适合：

- 群像运动。
- 指定相机运动。
- 需要沿用前一镜动作节奏的镜头。

### text_to_video

只用于无固定角色、无关键场景连续性的过渡镜头。首批内容应少用。

### edit_only

概念字卡、停帧、裁切复用和纯剪映合成，不调用 Seedance。

## 3. 镜头拆分原则

- 每个生成任务只设置一个主要动作。
- 每个任务只设置一种主要运镜。
- 默认生成 4–8 秒的素材片段；时间线更长时，在剪映中使用停帧、变速、裁切或同镜头 B 版补足。
- 不要求模型在一个片段中完成复杂的起承转合。
- 群像镜头控制人数，优先表现整体方向，不追求每个人独立表演。
- 同一角色跨镜头时，连续使用同一锚点图，不重新描述外形。

## 4. Prompt 结构

每个 Seedance Prompt 按以下顺序：

1. **输入参考说明**：哪张图约束角色，哪张图约束环境。
2. **镜头初始状态**：人物、物体、时间、天气、空间位置。
3. **唯一主要动作**：谁做什么，从什么状态到什么状态。
4. **主要运镜**：推、拉、横移、轻微手持或固定镜头。
5. **节奏和情绪**：缓慢、克制、焦虑扩散等。
6. **连续性**：服装、光线、水位、物体数量必须延续哪一镜。
7. **音频策略**：静音、只保留环境声，或允许生成指定声音。
8. **禁止项**：不说话、不生成字幕、不改变角色、不增加人物。

## 5. 旁白和原生音频

本栏目不让角色承担讲解口播，原因是：

- 知识术语必须逐字准确。
- 同一账号需要稳定旁白人格。
- 角色说话会提高口型、声线和台词漂移风险。
- 后期很难局部替换错误台词。

默认 `audio_mode`：

- `silent`：纯视觉镜头。
- `ambience_only`：可生成水声、脚步、风声等环境声。
- `keep_if_usable`：生成后人工判断，不能影响旁白。

剪映中旁白始终是主音轨，Seedance 原生音频只作为可替换环境层。

## 6. 连续性策略

### 角色

- 角色设定图 → 本期主锚点 → 镜头参考帧 → Seedance。
- 不直接用文字重新创造已存在的角色。
- 若角色脸部漂移，回到参考帧而不是在视频 Prompt 中堆叠更多外貌描述。

### 场景

- 先生成场景空镜锚点。
- 同一地点保持井台、道路、房屋和光源方向。
- 只允许故事需要的变量变化，例如水位、队伍长度和天气。

### 镜头衔接

- 前一镜结束姿态尽可能与后一镜参考帧接近。
- 关键动作可生成 A/B 两版，剪映选择更自然的衔接点。
- 不依赖 AI 自动生成长段多镜头叙事来保证整期连续。

## 7. G4 视频审核

每条片段记录以下结果：

- identity_consistency：角色是否可识别。
- motion_quality：动作是否自然且完整。
- camera_adherence：运镜是否符合要求。
- scene_continuity：场景、水位、时间是否连续。
- artifact_free：肢体、容器、背景是否无明显变形。
- audio_usability：环境声能否使用。
- editability：是否存在可用的入点和出点。

任一关键项失败，只重生成该片段。连续失败两次时，降低动作复杂度或改为静帧微动，不继续硬顶。

## 8. MVP 与 API 阶段

### MVP

- 人工把 `video-manifest.json` 中每个任务复制到 Seedance 界面。
- 按 `clip_id` 保存结果。
- 每个关键片段生成 2 个候选版本。
- 通过 G4 后再进入剪映。

### API 化

等栏目验证后，再实现：

- Seedance provider adapter。
- 任务提交、轮询、下载和失败重试。
- Prompt 与参考素材哈希。
- 成本、耗时、成功率和返工次数记录。
- 内容安全与授权元数据。
