# 剪映总装规范

## 1. 项目模板

建立长期复用的 9:16 模板，建议轨道从上到下为：

1. 概念揭晓和章节字卡
2. 主字幕
3. 视觉叠层和必要的静帧补位
4. Seedance 主视频片段
5. Seedance 可用环境声
6. 独立旁白
7. 补充音效
8. 背景音乐

统一参数：1080 × 1920、30 fps。顶部和底部各保留约 12%，左右各保留约 8%。

## 2. 装配顺序

1. 先导入独立旁白，锁定最终总时长。
2. 按 `edit-list.csv` 放入 Seedance 片段。
3. 优先围绕旁白切片，不强迫完整使用每条生成视频。
4. 片段不足时依次尝试：轻微变速、首尾停帧、裁切复用、静帧微动。
5. 导入 SRT 并人工修正断句。
6. 加入概念字卡、BGM、音效和栏目尾卡。

## 3. Seedance 片段处理

- 片段入点避开角色或物体尚未稳定的前几帧。
- 出点优先选择动作完成或短暂停顿处。
- 不使用明显变形的“精彩部分”。身份稳定比动作幅度重要。
- 相邻片段发生轻微跳变时，可用物体特写、环境空镜或 2–4 帧叠化缓冲。
- 不用复杂转场掩盖严重连续性错误，应回到 G4 返工。

## 4. 原生音频

- `silent`：直接关闭片段原声。
- `ambience_only`：只保留水声、脚步、风声等，明显低于旁白。
- `keep_if_usable`：人工试听后决定；含乱码对白、口型声或突兀音乐时立即静音。
- 旁白永远是主音轨。

## 5. 字幕和字卡

- 每屏 1–2 行，单行尽量不超过 16 个汉字。
- 每屏只高亮一个关键词。
- 概念名称只在揭晓节点首次出现。
- 不使用 Seedance 或 gpt-image-2 生成的文字。

## 6. 导出前检查

- 逐项核对 `edit-list.csv`。
- 所有片段均通过 G4 或明确采用静帧降级。
- 没有角色说出错误台词或出现无意义口型。
- 字幕不挡脸、不挡关键物体。
- 原生音频不盖旁白。
- 封面有冲突但不泄露答案。
- AI 生成内容标识完整。
