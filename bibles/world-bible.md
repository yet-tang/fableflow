# 世界观圣经：雾谷

## 1. 定位

“雾谷”是一个不对应具体国家和时代的寓言世界。它拥有村庄、集市、森林、河流、港口和城堡，可以承载心理学、经济学、社会学、管理学与 AI 概念。

世界观只负责提供稳定的叙事容器，不应抢过概念本身。

## 2. 空间隐喻

| 场景 | 常见隐喻 |
|---|---|
| 雾谷村 | 普通社会或组织 |
| 集市 | 市场、竞争、信息交换 |
| 城堡 | 制度、平台和规则制定者 |
| 森林 | 未知、风险、探索空间 |
| 河流/井/草场 | 共享资源或系统容量 |
| 港口 | 网络、协作与外部连接 |
| 钟楼 | 指标、期限或公共信号 |

这些只是候选映射，不是固定答案。每期仍需根据概念重新论证。

## 3. 世界规则

- 技术水平以手工业和轻奇幻为主，不出现手机、汽车和现代屏幕。
- 可以存在有单一规则的魔法物品，但魔法必须服务于概念机制。
- 制度制定者并非天然邪恶；错误结果可以来自信息不足、激励扭曲或个体理性叠加。
- 角色不以“好人/坏人”简单解释系统问题。
- 同一地点的建筑、色调和地理关系应长期稳定。

## 4. 叙述语气

- 像一个冷静、温和但知道结局的讲述者。
- 不卖弄古风，不使用大量生僻词。
- 允许轻微幽默，但不破坏悬念。
- 结尾揭晓后从寓言语言切换为通俗现代解释。

## 5. 连续性

常驻角色可以跨期出现，但每期必须让新观众独立理解。不得依赖前情才能看懂核心故事。
